# Django Online Course Assessment Submission

This package contains the files requested by the graded final-project assignment.

## Included artifacts

1. `models.py` — Question, Choice, and Submission models.
2. `admin.py` — seven model imports plus ChoiceInline, QuestionInline, QuestionAdmin, and LessonAdmin.
3. `03-admin-site.png` — admin-site screenshot showing Authentication and Authorization and OnlineCourse.
4. `course_details_bootstrap.html` — Bootstrap course detail template.
5. `views.py` — `submit` and `show_exam_result` functions.
6. `urls.py` — URL patterns for `submit` and `show_exam_result`.
7. `07-final.png` — successful mock-exam result screenshot.

## Suggested GitHub layout

Place these files in your Django app (for example, `onlinecourse/`) and push the project to GitHub.

Example URLs after publishing:

- `https://github.com/<YOUR_USERNAME>/<YOUR_REPO>/blob/main/onlinecourse/models.py`
- `https://github.com/<YOUR_USERNAME>/<YOUR_REPO>/blob/main/onlinecourse/admin.py`
- `https://github.com/<YOUR_USERNAME>/<YOUR_REPO>/blob/main/onlinecourse/course_details_bootstrap.html`
- `https://github.com/<YOUR_USERNAME>/<YOUR_REPO>/blob/main/onlinecourse/views.py`
- `https://github.com/<YOUR_USERNAME>/<YOUR_REPO>/blob/main/onlinecourse/urls.py`

The PNG files should be uploaded/submitted directly to the assignment where screenshots are requested.
